    Class MatrixClient

    Thin wrapper over the Matrix Client-Server API for one homeserver and session.

    Remarks

    Split into partial files by spec area:

    • MatrixClient.Auth.cs: server info, login and logout.
    • MatrixClient.Sync.cs: sync, sync loop and filters.
    • MatrixClient.Rooms.cs: room membership, creation, aliases, state and members.
    • MatrixClient.Events.cs: room history, sending, redaction, typing and read markers.
    • MatrixClient.Profile.cs: profiles and presence.
    • MatrixClient.AccountData.cs: account data, tags, ignored users and direct rooms.
    • MatrixClient.PushRules.cs: push rules and pushers.
    • MatrixClient.Directory.cs: public room directory and user directory.
    • MatrixClient.Media.cs: media upload and download, file messages.
    • MatrixClient.Devices.cs: devices and user-interactive auth.
    • MatrixClient.Keys.cs: encryption keys and to-device messages.
    • MatrixClient.Admin.cs: server administration, for admins.
    • MatrixClient.Rtc.cs: MatrixRTC transports, OpenID tokens and delayed events.
    Examples
    MatrixClient client = new(http, new Uri("https://matrix.org"));
await client.LoginWithPasswordAsync("@alice:matrix.org", password);
await foreach (SyncResponse sync in client.SyncLoopAsync(cancellationToken: cancellationToken))
    foreach ((string roomId, JoinedRoom room) in sync.Rooms.Join)
        foreach (ClientEvent ev in room.Timeline.Events)
            if (ev.TryGetContent(out MessageContent? message)) Console.WriteLine($"{ev.Sender}: {message.Body}");
