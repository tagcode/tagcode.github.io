    Class OlmMachine

    End-to-end encryption state machine of one device: keys, Olm sessions with other devices and Megolm sessions for rooms.

    Namespace: Uniform.Matrix.Protocol.Crypto
    Assembly: Uniform.Matrix.Protocol.Crypto.dll
    Syntax
    public sealed class OlmMachine : IDisposable
    Remarks

    Feed every sync to ReceiveSyncAsync(SyncResponse, CancellationToken), decrypt m.room.encrypted timeline events with DecryptRoomEventAsync(string, ClientEvent, CancellationToken), and encrypt outgoing events for encrypted rooms with EncryptRoomEventAsync(string, string, object, IReadOnlyCollection<string>, EncryptionContent?, CancellationToken). Calls are serialized, so it can be shared between threads. Split into partial files:

    • OlmMachine.cs: account, key upload and device lists.
    • OlmMachine.Olm.cs: Olm sessions and to-device messages, including received room keys.
    • OlmMachine.Megolm.cs: room message encryption, key sharing and decryption.
    • OlmMachine.CrossSigning.cs: cross-signing keys, trust and recovery from secret storage.
    • OlmMachine.Backup.cs: server-side key backup.
    • OlmMachine.KeyRequests.cs: room key and secret requests between the user's own devices.
    • OlmMachine.Verification.cs: SAS emoji verification of devices.
    Examples
    OlmMachine machine = await OlmMachine.CreateAsync(new MatrixKeyTransport(client), store, client.UserId!, client.DeviceId!, pickleKey);
await foreach (SyncResponse sync in client.SyncLoopAsync())
{
    await machine.ReceiveSyncAsync(sync);
    // decrypt timeline events with machine.DecryptRoomEventAsync(roomId, ev)
}
