    Uniform.Matrix.Protocol.Server

    Pure protocol code of a homeserver, without storage: room versions 10, 11 and 12 (RoomVersion), the event format, content hashes, reference-hash event IDs, signing and redaction (EventFormat), the auth events selection and the authorization rules (AuthEvents, AuthRules), power levels, push rule evaluation (PushRules), signed requests between servers (FederationAuth), server names (ServerNames), room server ACLs (ServerAcl) and DNS SRV messages (DnsSrv).

    It is used by Uniform.Matrix.Server, and builds on Uniform.Matrix.Protocol.Crypto for Ed25519 signatures.

    State resolution

    When a room's history forks, as when two servers send events at the same time, StateResolution.Resolve merges the states of the branches as the spec's state resolution v2 says, and with the v2.1 changes of room version 12. Keys every branch agrees on are kept. Conflicted power events (power levels, join rules, kicks and bans) are applied first, strongest sender first, each checked with AuthRules against what is resolved so far; the other conflicted events follow, ordered by the power levels they were sent under.

    The caller passes the events of the states and their auth chains:

    Dictionary<(string Type, string StateKey), string> merged = StateResolution.Resolve(RoomVersion.V12, [stateOfBranchA, stateOfBranchB], eventsById);

    AuthRules.CheckAuthChains checks received state, such as a joined room's, against each event's own auth events.
