    Uniform.Matrix.Protocol.Client

    MatrixClient wraps one homeserver and one session. It is split into partial files by spec area. Each endpoint is one method that sends a request and returns a response record. All requests go through a single private SendAsync, which:

    1. adds the bearer token for authenticated endpoints, and refuses to send if not logged in;
    2. serializes the body with MatrixJson.Options;
    3. retries rate-limited requests up to MaxRateLimitRetries times, waiting as long as the server asks, unless that is longer than MaxRateLimitDelay;
    4. turns other non-2xx responses into a MatrixException when the body is a standard error, or an HttpRequestException otherwise.

    Path segments such as room IDs (!abc:server), aliases (#room:server) and event IDs are always percent-escaped. The caller owns the HttpClient, which keeps the library usable with IHttpClientFactory, custom handlers and test stubs.

    Session

    After login, Session holds a MatrixSession with homeserver, user ID, device ID and access token. Store it and pass it to the MatrixClient(HttpClient, MatrixSession) constructor to resume without logging in again.

    Sync

    SyncLoopAsync is the main way to receive events. It long-polls sync, passes each next_batch as the next since, and yields every response. Transient failures (network errors, 5xx, timeouts, rate limiting) are retried with exponential backoff between SyncRetryDelay and SyncRetryMaxDelay; other errors, such as an expired token, end the loop with an exception.

    User-interactive auth

    Some endpoints, such as deleting devices, answer the first request with 401 and a body listing accepted auth flows and a session ID. Such bodies have no errcode, so the request pipeline maps them to UserInteractiveAuthException before ordinary Matrix errors. Methods that need it take a password and answer a m.login.password challenge themselves; without a password the exception reaches the caller, who can ask the user and call again.

    Discovery

    HomeserverDiscovery.DiscoverAsync follows server discovery: it reads https://{server}/.well-known/matrix/client and falls back to https://{server}/ when the file does not exist.
