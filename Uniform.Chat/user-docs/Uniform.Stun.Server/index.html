    Uniform STUN Server

    uniform-stun-server is a STUN and TURN server. It relays voice and video calls between people whose networks block direct connections, as on mobile networks and behind strict firewalls. Matrix homeservers such as Synapse hand out its credentials to their users' calls; Uniform Chat Server has the same server built in.

    • Running: ports, first start, and as a service.
    • Settings: every setting.
    • Homeservers: connecting it to Synapse or Uniform Chat Server.
