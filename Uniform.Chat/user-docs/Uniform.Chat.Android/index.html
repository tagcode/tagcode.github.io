    Uniform Chat for Android

    A chat app for Matrix, the open chat protocol, for Android phones and tablets: rooms, formatted messages, replies and reactions, files, invites, and end-to-end encryption with recovery and emoji verification. Messages you write are kept on the phone until the server has them, so nothing is lost when the connection drops.

    Note

    The app is in early development.

    • Installing: with F-Droid, and ntfy for notifications.
    • Getting started: sign in, and where your data is kept.
    • Rooms: the room list, joining and creating rooms.
    • Messages and files: writing, replies, reactions and files.
    • Security: encryption, recovery key and verification.
    • Notifications: when and how the app tells you about messages.
    • Settings: what can be changed.
    • Phones and narrow windows: the one-pane layout.

    It is the same app as the one for Windows and Linux; see its guide. There is also a client for the text terminal, see its guide, and to run a homeserver of your own, see the server guide.
