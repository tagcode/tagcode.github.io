    Uniform Chat Terminal

    A chat client for Matrix, the open chat protocol, that runs in a text terminal: menus, a room list, the message log and members, an input line for messages and irssi-style /commands, and a status bar. It supports end-to-end encrypted rooms and files, key backup with a recovery key, and emoji verification of devices. Messages you write are kept on your computer until the server has them, so nothing is lost when the connection drops.

    Note

    The client is in early development.

    • Installing: with apt on Debian and Ubuntu, or from the release archives.
    • Getting started: run and log in.
    • Interface: the window, menus and keys.
    • Messages: formatting, replies, edits, reactions and more.
    • Files and images: sending, saving and image previews.
    • Encryption and devices: recovery key, key backup and verification.
    • Room administration: names, avatars, kicks, bans and power levels.
    • Commands: the /commands of the input line.
    • Settings: command-line parameters, the settings file and logs.

    There is also a graphical app for Windows, Linux and Android; see its guide. To run a homeserver of your own, see the server guide.
